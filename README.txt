# Tushar & Anjali Wedding Invitation

A mobile-friendly wedding invitation website starter.

## Included
- Couple photos
- Opening animation
- Wedding date
- Countdown
- Venue section
- Wedding-day schedule
- RSVP WhatsApp button
- Responsive mobile design

## Before publishing
1. Confirm the complete venue address.
2. Replace the placeholder wedding timings in `index.html`.
3. Replace the RSVP WhatsApp link with the groom/bride/family WhatsApp number.
4. Upload this folder to a GitHub repository and enable GitHub Pages.

The Google Maps button currently searches for “Babasaheb Khedkar”; this should be changed to the exact venue once the full address is confirmed.
